# Handwriting Plotter APK

1. Create a free account at github.com and make a new repository.
2. Upload everything in this folder (including the hidden .github folder) to it.
3. Open the Actions tab, pick "Build APK", and click Run workflow (it also runs on every upload).
4. After about 4 minutes, open the finished run and download the artifact "handwriting-plotter-apk". Unzip it to get app-debug.apk.
5. Copy the APK to your phone and open it. Allow "install unknown apps" if Android asks.

Inside the app, "Download .gcode" opens the Android share sheet, so you can save the file to Files or Drive or send it to another app.
